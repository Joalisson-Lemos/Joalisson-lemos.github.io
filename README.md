## 📌 Sobre este projeto

Este repositório é o meu **portfólio pessoal**, construído do zero para apresentar quem sou, as tecnologias que domino e os projetos que desenvolvi. O foco foi criar uma experiência visual moderna, responsiva e de carregamento rápido.

---

## 🚀 Tecnologias utilizadas

| Tecnologia | Função |
|---|---|
| [React.js](https://reactjs.org/) | Biblioteca para construção de interfaces componentizadas |
| [Tailwind CSS](https://tailwindcss.com/) | Estilização utilitária com design system consistente |
| [React Router DOM](https://reactrouter.com/) | Roteamento client-side |
| [Vite](https://vitejs.dev/) | Build tool ultrarrápida para desenvolvimento moderno |
| [EmailJS](https://www.emailjs.com/) | Envio de e-mails diretamente do front-end |
| [Material Tailwind](https://www.material-tailwind.com/) | Componentes UI com Material Design |
| [React Icons](https://react-icons.github.io/react-icons/) | Ícones de tecnologias e redes sociais |

---

## ✨ Funcionalidades

- **Hero animado** com efeito de digitação em tempo real
- **Carrossel de tecnologias** com scroll infinito automático
- **Galeria de projetos** com modal de detalhes, navegação por setas e dots
- **Formulário de contato** funcional integrado ao EmailJS
- **Links de redes sociais** (WhatsApp, LinkedIn, GitHub)
- **Design responsivo** para mobile, tablet e desktop
- **Menu hambúrguer** para telas pequenas

## ⚙️ Como rodar localmente

```bash
# Clone o repositório
git clone https://github.com/Joalisson-Lemos/Joalisson-lemos.github.io.git

# Entre na pasta
cd Joalisson-lemos.github.io

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

O projeto estará disponível em `http://localhost:5173`.
